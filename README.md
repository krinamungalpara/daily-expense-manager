# Daily Expense Manager

A simple and efficient **console-based Expense Manager** developed in **C++** using fundamental **Object-Oriented Programming (OOP)** concepts.

##  Overview

The Daily Expense Manager allows users to record, view, analyze, and manage their daily expenses through an interactive console-based menu.

This project was created to practice C++ programming fundamentals and understand how OOP concepts can be applied to a practical application.

##  Features

*  Add a new expense
*  View all recorded expenses
*  Calculate total spending
*  Find the highest expense
*  Calculate category-wise spending
*  Delete an expense
*  Basic input validation
*  Exit the application safely

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/daily-expense-manager.git
```

### 2. Open the project

Open `ExpenseManager.cpp` in a C++ IDE or code editor.

### 3. Compile

```bash
g++ src/ExpenseManager.cpp -o ExpenseManager
```

### 4. Run

```bash
./ExpenseManager
```

On Windows, you can run:

```bash
ExpenseManager.exe
```
